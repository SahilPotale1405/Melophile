# 🎸 Melophile Academy Management System

A complete Guitar Academy Management System built using:

- React
- Node.js
- Express.js
- MongoDB
- Tailwind CSS

## Features

- Student Management
- Session-Based Attendance
- Demo Booking
- Online Classes
- Fee Management
- Admin Dashboard
- Student Dashboard
- Contact Form
- EmailJS Integration
